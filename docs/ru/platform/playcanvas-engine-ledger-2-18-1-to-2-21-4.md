# Журнал обновления PlayCanvas Engine: 2.18.1 → 2.21.4

Этот журнал фиксирует повышение версии runtime-зависимости `playcanvas` с `2.18.1` до `2.21.4` в каталоге pnpm-workspace и сопоставляет каждое upstream-критическое изменение с локальной поверхностью.

Профиль локального использования (проверено grep 2026-08-22): строго WebGL2-рендеринг, процедурные примитивы (`BoxGeometry`, `SphereGeometry`), `StandardMaterial`, создание `MeshInstance` как `new pc.MeshInstance(mesh, material)` в `packages/universo-react-playcanvas-engine/src/runtime.ts` (~строка 147). Локально в `packages/universo-react-playcanvas-engine/src/` и исходниках PlayCanvas-виджета `apps-template-mui` нет аудиовоспроизведения, GSplat, XR и WebGPU. Upstream-изменения, затрагивающие только examples, игнорируются.

## Значимые исправления поведения, релевантные локальной поверхности

Некритические исправления, затрагивающие пути WebGL2/процедурной геометрии/материалов/жизненного цикла canvas, на которые опирается этот репозиторий:

-   `v2.19.0`: opacity dither теперь полностью скрывает при alpha 0 и полностью показывает при alpha 1 ([#8767](https://github.com/playcanvas/engine/pull/8767)) — делает чётче полупрозрачные края, создаваемые `createTranslucentStandardMaterial`; проверяется тестом `index.test.ts` “creates translucent materials with bounded opacity” плюс проверка браузерным прогоном mmoomm flows.
-   `v2.19.0`: retry-повторы загрузки ассетов включены по умолчанию ([#8744](https://github.com/playcanvas/engine/pull/8744)) — локальные сцены процедурные, поэтому поведение повторов касается только возможных будущих загрузок ассетов.
-   `v2.20.0`: сброс активной WebGL texture unit при инициализации устройства для переиспользуемых контекстов ([#8894](https://github.com/playcanvas/engine/pull/8894)) — укрепляет пути перемонтирования, покрываемые тестом `PlayCanvasCanvasWidget.test.tsx` “cleans up PlayCanvas and Colyseus resources on unmount before remounting a fresh room”.
-   `v2.20.0`: `app.assets` доступен сразу после создания AppBase ([#8952](https://github.com/playcanvas/engine/pull/8952)); `camera.screenToWorld` больше не возвращает NaN при вызове в `initialize` ([#8950](https://github.com/playcanvas/engine/pull/8950)) — укрепление жизненного цикла; локальная камерная математика ручная и не затронута.
-   `v2.21.0`: view-level uniforms переведены на uniform buffers в WebGL2 ([#8987](https://github.com/playcanvas/engine/pull/8987), [#8967](https://github.com/playcanvas/engine/pull/8967)) — внутреннее изменение WebGL2-конвейера, невидимое для API обёртки; покрывается браузерным прогоном mmoomm flows.
-   `v2.21.0`: конструктор устройства больше не падает, если у canvas нет `getBoundingClientRect` ([#9000](https://github.com/playcanvas/engine/pull/9000)); исправлены инвертированные флаги использования буфера в `Mesh.clear()` ([#9023](https://github.com/playcanvas/engine/pull/9023)).
-   `v2.21.4`: отбрасывание вне диапазона глубины в VSM shadow casters ([#9124](https://github.com/playcanvas/engine/pull/9124)) — N/A локально (VSM-теней нет).

## Проверенные факты

-   **npm integrity**: `sha512-L4UGy3z/YT8AaNBEY4ITsZup548UFMabF7loh0YQ0DRwQLdjIW8grmZPoQ1+B83+N6sejRS0/XlXV2Vfb11+fw==`, опубликовано `2026-08-13T11:52:03Z`.
-   **Влияние на бандл (до → после)**: главный чанк `5107.7 KiB` → `3085.3 KiB` raw, gzip `1439.6` → `916.7 KiB`. Движок вынесен в ленивый чанк `PlayCanvasCanvasWidget-*.js` (≈ `2033.5 KiB`), загружаемый только для виджетов `playcanvasCanvas`.
-   **Контракт идентичности canvas**: `createBasicApplication` принимает объект опций (`{ canvas, applicationId?, windowKeyboard? }`). При передаче `applicationId` он проставляется в `canvas.id`, так как движок ключует реестр приложений по id canvas; `destroy()` удаляет этот id обратно. Ввод с клавиатуры подключается к canvas, если не задан `windowKeyboard: true`, чтобы параллельные виджеты не перехватывали клавиатурные события друг друга.
-   **Терминальное состояние при отсутствии WebGL2**: когда WebGL2 недоступен, виджет пропускает монтирование движка и показывает локализованное терминальное состояние с ключом `playcanvasCanvas.webglUnavailable`; проверяется тестом `PlayCanvasCanvasWidget.test.tsx` “renders a localized terminal state and skips engine mount when WebGL2 is unavailable”.

## Решения о диспозиции

-   **Presence сделан явным**: `LocalPresence` теперь передаётся явно вместо неявных значений по умолчанию; подробности приведены в документации по multiplayer.
-   **Zod override оставлен на 3.x**: core-пакет декларирует peer-метаданные `^4.1.12` для совместимости с Zod 4, но override остаётся на 3.x, поскольку он влияет только на метаданные — отсутствие импортов `zod` в собранных core-билдах проверено 2026-08-22.
