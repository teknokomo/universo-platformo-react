## Ownership vocabulary

Every row has exactly one final owner from the approved set: entity, binding, placement, presentation, host-runtime, specialized-runtime, or retired.

-   entity: durable authored/domain content stored in the owning Entity/domain record.
-   binding: semantic source identity and bounded server-resolved source contract.
-   placement: widget instance identity, zone, parent/slot, activity/order, lineage, and placement policy.
-   presentation: renderer appearance or bounded user-facing display configuration.
-   host-runtime: current route/user/workspace/theme/locale/search/session/application metadata supplied by host capabilities.
-   specialized-runtime: typed module/report/LMS/PlayCanvas/Interpretation Network behavior or engine state.
-   retired: current field/shape/demo payload is deleted and rejected by the final contract.

The final contract uses neutral config.\_\_layout.bindings for semantic Entity bindings, strict registry-declared presentation/source metadata, and first-class placement rows. Physical IDs, arbitrary source/query records, embedded child placements, MUI demo content, and show\* composition booleans are not accepted by the clean final schemas.

## Classification notes requiring implementation-time confirmation

All current persisted paths above are classified; there are no unclassified fields. Three boundaries should be revalidated while Phase 1 types are finalized:

1. interpretationNetworkWorkspace source/model codenames and field mappings are classified as specialized-runtime because the current schema is a domain-specific typed surface. Any subset that selects genuinely Entity-owned supporting content should be split into neutral bindings without moving the remaining engine/view contract into generic Entity storage.
2. menuWidget start navigation is classified as binding/retired source identity. The generated variant may resolve the equivalent semantic start target entirely from host-runtime navigation metadata; the final registry should make the variant authority explicit.
3. resourcePreview source.launchMode is classified as presentation. If the resource domain later treats launch policy as immutable domain behavior, it can move into the typed resource projection, but it must not return to an unbounded renderer source object.
